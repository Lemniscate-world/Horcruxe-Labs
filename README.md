# Horcruxe Labs

Labo de recherches personnelles. Chaque recherche a son dossier isolé sous `recherches/NNN-nom/`, avec son code, ses notes, et ses papiers.

## Structure

```
Horcruxe Labs/
  README.md
  RESEARCH_MAP.md          # index de toutes les recherches
  papers/                  # index global des papiers publiés / en cours
  templates/
    RECHERCHE_TEMPLATE.md  # pour créer recherche N+1
    PAPER_TEMPLATE.md      # pour chaque nouveau papier
  recherches/
    001-memoire-araignee/  # Recherche 001 : Mémoire Araignée / SpiderCache
      README.md
      ROADMAP_TOILES.md
      notes/               # tes recherches, en français, datées
      code/                # code isolé et reproductible
      tests/
      papers/              # drafts + publiés de CETTE recherche
      references/          # PDFs, liens, bib
```

## Règles

1. Une recherche = un dossier `recherches/NNN-slug/`. On n'en fera plusieurs.
2. On ne modifie jamais `russel-agent/` depuis ici. Ici c'est la version labo, propre, publiable.
3. Provenance toujours notée : d'où vient le code, quel commit / quel fichier.
4. Chaque papier a son dossier `papers/draft-XXX-slug/` avec outline, figures, bib.
